# Reviews

This folder contains draft and approved review assets for **Beyond Chat**.

Review assets are not manuscript chapters. They are tools used to inspect the
book's writing, structure, teaching flow, and project usefulness.

Status rules:

- Draft review assets may guide discussion but are not project law.
- Approved review assets can be used during chapter reviews and Bookwright role
  creation.
- Review assets inspired by creators must not copy their prose, titles,
  diagrams, or distinctive phrasing.
