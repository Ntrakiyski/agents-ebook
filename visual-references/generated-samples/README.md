# Generated Visual Samples

These are approved sample directions for **Beyond Chat** chapter visuals.

The accepted direction:

- White or warm-white ebook page background.
- Hand-drawn marker style.
- Charcoal/black lines for structure and arrows.
- Small colored outline accents for meaning:
  - blue for AI/context/agent capability
  - red for human/review/control
  - green for knowledge/files/project memory
  - purple/yellow only when extra categories are needed
- Vertical composition with generous empty space.
- Short labels only; avoid paragraph text inside images.
- Simple icons and rounded arrows.
- No dark background, gradients, stock-art feel, 3D rendering, clutter, or
  decorative blobs.

## Samples

- `01-cloud-chat-to-local-agent.png` - Chapter 1/onboarding concept: moving from
  cloud chat to a local agent that can help build ATLAS.
- `02-context-to-grounded-answer.png` - Context/RAG concept: notes, docs, and
  memory are selected into context before producing a grounded answer.
